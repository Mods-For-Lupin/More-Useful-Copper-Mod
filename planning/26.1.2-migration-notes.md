## Key API Lookup Results

```
neighborChanged new sig:
  protected void neighborChanged(BlockState, Level, BlockPos, Block, @Nullable Orientation, boolean)

affectNeighborsAfterRemoval (was onRemove):
  protected void affectNeighborsAfterRemoval(BlockState, ServerLevel, BlockPos, boolean)

ThrowableItemProjectile constructors:
  (EntityType, Level)
  (EntityType, LivingEntity, Level, ItemStack)
  (EntityType, double, double, double, Level, ItemStack)

EntityType.create:
  @Nullable T create(Level level, EntitySpawnReason reason)
  @Nullable T create(ServerLevel, Consumer<T>, BlockPos, EntitySpawnReason, boolean, boolean)

EntitySpawnReason: no SPAWN_EGG — use SPAWN_ITEM_USE

DustParticleOptions: (int color, float scale)  // no longer Vector3f

TooltipDisplay: net.minecraft.world.item.component.TooltipDisplay

ARGB: net.minecraft.util.ARGB
  ARGB.color(Vec3)  // converts normalized floats to int rgb

TargetingConditions.Selector: boolean test(LivingEntity, ServerLevel)

LevelData.getRespawnData().pos()  // replaces getSharedSpawnPos()

CompoundTag.getBoolean(String) → Optional<Boolean>
CompoundTag.getBooleanOr(String, boolean) → boolean

BlockPos NBT: putLong(key, pos.asLong()) / BlockPos.of(tag.getLongOr(key, 0))

Entity.moveTo() REMOVED — replacements:
  snapTo(double x, double y, double z, float yRot, float xRot)  // position + rotation
  setPos(Vec3)  // position only
  absSnapRotationTo(float yRot, float xRot)  // rotation only

Blocks.CHAIN → Blocks.IRON_CHAIN  // vanilla chain renamed

LivingEntity.getArmorSlots() REMOVED — replacement:
  for (EquipmentSlot slot : EquipmentSlot.VALUES) {
      if (!slot.isArmor()) continue;
      ItemStack stack = living.getItemBySlot(slot);
      // ... living.setItemSlot(slot, stack);
  }

Sheep.shear(SoundSource) → shear(ServerLevel, SoundSource, ItemStack)

Item.getDescriptionId(ItemStack) REMOVED — override getName(ItemStack) returning Component instead

IPlatformHelper.tileBuilder() returns BlockEntityType<T> directly — no .build() call needed

CustomData.contains(String) REMOVED — use customData.copyTag().contains(String)

Sheep class moved: net.minecraft.world.entity.animal.Sheep → net.minecraft.world.entity.animal.sheep.Sheep

SpawnEggItem: DeferredSpawnEggItem removed. Colors removed (data-driven).
  new SpawnEggItem(properties.spawnEgg(entityType))  // properties.spawnEgg() sets the entity type

BlockEntityType.Builder REMOVED from vanilla — platform-specific replacements:
  Fabric:   FabricBlockEntityTypeBuilder.create(factory, blocks).build()
            (net.fabricmc.fabric.api.object.builder.v1.block.entity.FabricBlockEntityTypeBuilder)
  NeoForge: new BlockEntityType<>(constructor::apply, Set.of(validBlocks))
            (constructor made public via AT in accesstransformer.cfg line 238)

FMLLoader static methods REMOVED:
  isProduction() → FMLEnvironment.isProduction()
  getDist()      → FMLEnvironment.getDist()
  getGamePath()  → FMLLoader.getCurrent().getGameDir()

FabricItemGroup → FabricCreativeModeTab (net.fabricmc.fabric.api.creativetab.v1)

Block color registration (Fabric): ColorProviderRegistry removed
  BlockColorRegistry.register(List<BlockTintSource>, Block...)
  BlockTintSource = functional interface: int color(BlockState state)  // world/pos not available in basic method

Block color registration (NeoForge): RegisterColorHandlersEvent.Block removed
  Use RegisterColorHandlersEvent.BlockTintSources instead — same List<BlockTintSource> API

BlockRenderLayerMap (Fabric) REMOVED — use "render_type" in block model JSON

BlockEntityWithoutLevelRenderer REMOVED in 1.21.5+ — custom item rendering needs new ItemModel API

EntityModelLayerRegistry (Fabric API) REMOVED — no code-side replacement; model layers now data-driven
  NeoForge still registers via EntityRenderersEvent.RegisterLayerDefinitions
```
